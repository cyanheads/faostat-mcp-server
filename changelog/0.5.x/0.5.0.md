# 0.5.0 — 2026-10-28

## Added

- Publish faostat-guide as the MCP resource skill://faostat-guide/SKILL.md for coverage-aware comparisons and staged SQL analysis.
- **Agent Plugins** root `plugin.json` and `mcp.json` support standard plugin discovery; the guide ships through npm, Docker, and MCPB.

## Changed

- **Framework runtime** adopts the HTTP request-retention fix from mcp-ts-core 0.13.17 and skill delivery from 0.13.18; DataCanvas uses DuckDB 2.
- **Documentation and development tooling** refresh framework guidance, simplify installation, consolidate bug-report environment fields, validate skill packaging, and set dependency minimum release age to one day.
- **Table expiry documentation** describes `expires_at` as the timestamp recorded at staging instead of claiming each staged-table operation refreshes it.

## Fixed

- **MCPB runtime modules** survive documentation filtering at dependency package roots, preserving nested SDK skill modules (cyanheads/mcp-ts-core#794).
- **MCPB contents** exclude root development paths, node-gyp build output, and build-only framework/SQLite files while retaining compiled native addons.
