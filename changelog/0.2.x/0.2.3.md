# 0.2.3 — 2026-08-24

## Added

- **MCP 2026-07-28 support** alongside initialize-negotiated 2025 clients.
- **`faostat_dataframe_describe` pagination.** The listing previously returned every staged table with no cap, growing unbounded across a session that spilled repeatedly. `limit` (default 20, max 100) and `offset` page the newest-first listing; `totalMatches`, `truncated`, and `nextOffset` enrichment disclose the cap and the next page. An offset past the end reports as such rather than as an empty canvas; a `name` lookup stays single-page.

## Changed

- **Tool contracts reject undeclared root inputs** and advertise SDK-valid structured error envelopes.
- **Advertised JSON Schema is 2020-12**, not draft-07.
- **Session mode is explicitly stateless** across `.env.example`, the Docker image, and the README.
- **Mirror sync logging adapts to the framework's closed `RequestContext`** — per-line metadata now rides on a synthetic operation context's `additionalContext` instead of loose top-level keys.
- **Docker build stage pins `--platform=$BUILDPLATFORM`.** `bun run build` emits platform-independent JS, so the stage has no reason to run under emulation — and under QEMU it aborted outright on an arm64 host. Base images move to `oven/bun:1.4.0`(`-slim`).
- **Production image's OTel install adds `--omit=peer`**, keeping the framework's optional peer tiers (a test runner, several service SDKs) out of the image.
- **Security reporting** uses `security@caseyjhand.com`.
- **Build and release maintenance** adopts Bun 1.4, current packaging scripts and skills, and community health files (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`).
