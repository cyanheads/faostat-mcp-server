# 0.4.1 — 2026-10-25

## Changed

- **Framework runtime** uses Markdown-safe error text while preserving the original structured message, names invalid numeric settings at startup, settles cancelled calls as `RequestCancelled`, and drains HTTP requests with `503` responses.
- **Development tooling and docs** refresh framework guidance, classify audit advisories against the installed root dependency, and document hosted-client configuration for Claude Code, Cline, Cursor, and Claude Desktop.

## Fixed

- **`CANVAS_PROVIDER_TYPE`** defaults blank, whitespace-only, and whole-value placeholder settings to `duckdb`; an explicit `none` still disables analytical staging.
- **Worker-retirement test** holds worker exits explicitly instead of relying on native-query timing.
