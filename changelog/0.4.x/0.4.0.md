# 0.4.0 — 2026-10-17

## Added

- **`test:coverage`** enforces inherited coverage thresholds across reachable source, with native worker behavior covered by both Bun and Node integration tests ([#39](https://github.com/cyanheads/faostat-mcp-server/issues/39)).

## Changed

- **Dataframe SQL** now rejects `current_setting()`, `current_schema()`, `current_schemas()`, `in_search_path()`, `query_table()`, and computed `query()` SQL; use direct `SELECT` statements or literal `query()` SQL.

## Fixed

- **`faostat_commodity_profile`** selects one QCL item using `item_code` or a unique label/search match; ambiguous queries return bounded candidates and guidance to select a code ([#41](https://github.com/cyanheads/faostat-mcp-server/issues/41)).
- **Single-area observation pages** use an `(area_code, year)` index installed in the background on existing mirrors without a re-sync ([#34](https://github.com/cyanheads/faostat-mcp-server/issues/34)).
- **Aggregate exclusion** classifies sub-threshold EU trade blocs and Sub-Saharan Africa as aggregates across resolution, pages, streams, rankings and trends ([#40](https://github.com/cyanheads/faostat-mcp-server/issues/40)).
- **`faostat_dataframe_drop`** explains that a missing canvas has nothing left to drop and points to the session's remaining staged tables.
- **MCPB packaging** excludes development source, tests, coverage and cache artifacts.
