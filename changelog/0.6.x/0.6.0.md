# 0.6.0 — 2026-11-03

## Added

- **Item selectors:** `code_text` resolves exact alphanumeric items; `item_codes_text` selects them in observations and element discovery, mutually exclusive with numeric item selectors. ([#48](https://github.com/cyanheads/faostat-mcp-server/issues/48))
- **Element discovery:** element matches include observed `units`, optionally scoped by `item_codes` or `item_codes_text`; empty observation queries with explicit items and elements return `available_elements` without claiming area/year/source coverage. ([#54](https://github.com/cyanheads/faostat-mcp-server/issues/54))
- **Item groups:** verified QCL and TCL groups return `kind: "aggregate"`; unclassified items remain null and are not certified safe to sum. Query inclusion stays unchanged. ([#55](https://github.com/cyanheads/faostat-mcp-server/issues/55))
- **Source selection:** `source_codes` selects exact methodologies; omitted selection returns every source, with `source_code` and `source` preserved inline, in staged SQL, and in query provenance. ([#49](https://github.com/cyanheads/faostat-mcp-server/issues/49))

## Changed

- Numeric item codes are nullable for alphanumeric FAOSTAT items; exact text codes are returned separately.
- **Mirror upgrades:** run `mirror:refresh` after upgrading. FS/GLE rebuild once despite unchanged upstream dates and remain unready until completion; compatible numeric domains stay readable and prepare new indexes during refresh.
- **faostat-guide 1.0 → 1.1:** document text identities, reporting periods, bounds, source selection, units, and overlapping item groups; server and SQL guidance follow the same analytical constraints.
- **Test workers:** bound concurrent Vitest workers to four for fixtures that own native SQLite and DuckDB engines.

## Fixed

- **FS ingestion:** retain period and alphanumeric-item rows plus censored bounds; preserve the original `period`, use its integer midpoint for year filtering, and expose `value_qualifier` beside the numeric bound on both output surfaces and in staged schemas.
- **GLE identity:** include source identity in observation keys so competing estimates coexist; numeric annual source-less keys retain their existing form.
- **Resolver readiness:** unsynced item/element domains return retryable `index_not_ready` with sync recovery instead of spelling advice; areas retain shared-vocabulary lookup. ([#53](https://github.com/cyanheads/faostat-mcp-server/issues/53))
- **Missing item cells:** skip absent item identities in data and dimension CSV rows instead of inventing numeric zero.
