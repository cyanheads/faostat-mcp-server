# 0.7.2 — 2026-11-20

## Changed

- **Food Balances item codes:** `faostat_resolve_codes` marks 24 verified Food Balances (`FBS`) groups and totals as `aggregate` on existing mirrors. ([#69](https://github.com/cyanheads/faostat-mcp-server/issues/69))
- **Cube index preparation:** refresh installs missing indexes on a worker under the sync lease before advancing the cube revision. ([#70](https://github.com/cyanheads/faostat-mcp-server/issues/70))
- **Text search:** `faostat_resolve_codes` and `faostat_commodity_profile` run text searches on read workers and honor cancellation and query timeouts. ([#73](https://github.com/cyanheads/faostat-mcp-server/issues/73))
- **`mirror:refresh`:** uses a two-minute window per domain to start retries for lease and pre-claim SQLite contention. An in-progress SQLite lock wait can finish after the window. The refresh continues with later domains and exits nonzero with any skipped codes. ([#74](https://github.com/cyanheads/faostat-mcp-server/issues/74))

## Fixed

- **Planner statistics:** a running server detects stale statistics after an interrupted external refresh and reloads worker connections when another process publishes fresh statistics. Closing builds use the domain lease to coordinate with other refreshes and readers. ([#72](https://github.com/cyanheads/faostat-mcp-server/issues/72))
- **MCPB installer:** the description reflects the bundle's stdio transport and SQLite mirror. ([#75](https://github.com/cyanheads/faostat-mcp-server/issues/75))
